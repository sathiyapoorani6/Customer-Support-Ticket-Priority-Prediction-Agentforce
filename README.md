# Customer Support Ticket Priority Prediction and Automated Assignment System Using Agentforce
## Project Overview
This project is a Salesforce-based customer support solution that automatically analyzes support tickets, determines their priority level, and triggers appropriate support automation using Salesforce Flow and Agentforce.

## Features
- Customer support ticket management
- Automatic priority classification: High, Medium, and Low
- Ticket description analysis
- Automatic urgent task creation for High-priority tickets
- Assignment to Senior Support Agent for High-priority cases
- Salesforce Auto-Launched Flow automation
- Agentforce conversational support
- Flow integration with Agentforce using Agent Actions

## Technologies Used
- Salesforce
- Salesforce Flow
- Agentforce
- Salesforce Custom Objects
- Tasks and Automation

## Priority Logic
- **High:** urgent, not working, failure
- **Medium:** issue, slow, delay
- **Low:** none of the above keywords

## Project Workflow
Account Name → Latest Support Ticket → Description Analysis → Priority Classification → Agent Assignment → Urgent Task Creation → Agentforce Response

## Result
The system successfully analyzes customer support tickets and returns the ticket priority, assigned support level, and action message through Agentforce.
